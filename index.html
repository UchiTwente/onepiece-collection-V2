☁ Synchronisation automatique PC ↔ iPhone (activer une seule fois)

Configuration : (1) crée ton projet sur Supabase ; (2) exécute le SQL du fichier schema_supabase.sql dans SQL Editor ; (3) récupère Project URL et publishable key / anon key dans les paramètres API du projet ; (4) connecte-toi avec le même compte sur PC et iPhone. Commence par restaurer ta collection sur le PC et l’envoyer au cloud.

Pour une synchronisation automatique privée, configure ton projet Supabase personnel et utilise le schema_supabase.sql fourni. Ne colle jamais une clé secrète/service_role : utilise seulement une clé publique/anon et des règles RLS. Ouvre cette application sous un même lien HTTPS sur les deux appareils pour l'installation et la synchronisation.

Non connecté · La collection est enregistrée uniquement sur cet appareil.

Après connexion, l’application échange les changements au démarrage, à chaque retour dans l’app et périodiquement lorsqu’elle est ouverte. Une modification est envoyée après quelques secondes. En cas de déconnexion Internet, elle reste conservée sur ton appareil jusqu’à la prochaine synchronisation.

Les modifications sont envoyées vers le cloud après connexion et reçues lors des ouvertures suivantes. Si deux appareils modifient la même carte hors ligne, la version avec la date de modification la plus récente est privilégiée. Exporte aussi une sauvegarde JSON indépendante du service cloud.

Enregistrement : les cases cochées, les quantités et les notes sont sauvegardées localement dans ce navigateur. Avant de changer de version ou de navigateur, exporte ta sauvegarde JSON puis restaure-la dans la nouvelle version. Sur Chrome et Edge, le bouton « Activer la sauvegarde sur disque » permet aussi de synchroniser automatiquement un fichier JSON choisi pendant la session : rouvre ce fichier lors des prochaines sessions. Conserve une copie JSON datée sur un autre support. Les visuels s’affichent directement dans le tableau, mais leur chargement nécessite Internet ; ils ne sont pas stockés dans ce fichier HTML.

Catalogue : données provenant du dépôt Punk Records (données reprises des listes Bandai). Les index anglais et français sont fusionnés pour éviter la disparition des cartes classiques anciennes : si une source ne répond pas, les numéros de référence restent disponibles, mais les métadonnées non vérifiées sont signalées. Les versions _p1, _p2… et _r1… sont suivies séparément. Elles sont regroupées sous le numéro d’origine, même lorsqu’elles ont été distribuées dans une autre extension.
